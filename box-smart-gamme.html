Les box Jeedom Smart

La gamme Smart est composée de mini-ordinateurs compacts et économiques, parfaits pour débuter en domotique. Ils partagent tous la même base matérielle mais se distinguent par leur compatibilité avec différents protocoles domotiques.

Smart Z-Wave

Le modèle équipé d'une antenne Z-Wave pour contrôler vos appareils compatibles Z-Wave/Z-Wave+.

Idéal pour les installations domotiques basées sur ce protocole très répandu.

Guide de démarrage Smart Z-Wave

Smart EnOcean

Le modèle équipé d'une antenne EnOcean pour contrôler vos appareils compatibles avec ce protocole sans pile et écologique.

Parfait pour les installations privilégiant les appareils auto-alimentés sans batterie.

Guide de démarrage Smart EnOcean

Smart (sans antenne)

Le modèle de base, sans antenne préinstallée, mais compatible avec les dongles USB pour ajouter le protocole de votre choix.

Flexible, il peut être adapté selon vos besoins avec différents modules additionnels.
